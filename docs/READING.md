## Reading path

The book is written in Chinese. English repository guidance helps contributors; a complete English book is not available. Start with the preface and Part 1, install Racket/DrRacket as the chapters explain, then run small examples before moving on.

## Free access and content status

The book is free and needs no account. Chapters are educational material, not a promise that every example works on every Racket version, OS or hardware. Record your actual environment and compare errors with the chapter’s assumptions.

## Privacy and local data

Reading the static book does not require uploading code. The feedback widget opens a prefilled public GitHub issue; review selected text and the full report before submitting. External links and embedded third-party resources have their own data policies.

## Corrections, feedback and recovery

Use the page feedback entry or Issues, including chapter URL, selected passage, Racket version, OS and a minimal example. Avoid secrets and private project source. Keep your exercises in a separate backed-up project; browser history is not a backup. Contributors use the lockfile, content checks and static build before publication.
